# Music Player

Веб-приложение для прослушивания музыки с возможностью регистрации, создания списка избранного, поиска треков по жанрам и исполнителям. Проект реализован на стеке React, Node.js, PostgreSQL.

🔗 **Демо:** [https://music-one-ashy.vercel.app/#/](https://music-one-ashy.vercel.app/#/) (фронтенд, развёрнут на Vercel)

## Стек технологий
### Frontend
- React
- React Router
- HTML5, CSS3

### Backend
- Node.js + Express
- PostgreSQL
- Sequelize ORM
- JWT для аутентификации
- bcrypt для хеширования паролей
- Multer для загрузки аватарок
- CORS, dotenv
